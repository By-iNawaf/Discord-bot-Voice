✨ Features

* 🎙️ تشغيل وإدارة عشرات البوتات الصوتية.
* 🏠 تحديد قناة رئيسية لجميع البوتات.
* 🔀 نقل البوتات أو فصلها وإعادتها بأزرار تفاعلية.
* 🎛️ لوحة تحكم احترافية بتصميم Discord Components V2.
* 🌐 دعم العربية والإنجليزية.
* 👑 نظام مالك وإداريين بصلاحيات مخصصة.
* 💾 حفظ الإعدادات والحالات بعد إعادة التشغيل.
* 🔄 إعادة اتصال تلقائية ومراقبة دورية.
* ➕ إضافة البوتات وإدارتها من داخل اللوحة.

⚙️ Requirements

* Node.js >= 22.13
* Discord Bot Token
* Owner ID
* استضافة تدعم التشغيل المستمر والتخزين الدائم.

🚀 Quick Start

npm install
npm start

Configure your .env file:

DISCORD_TOKEN=YOUR_BOT_TOKEN
OWNER_ID=YOUR_DISCORD_ID
DEFAULT_LANG=ar
