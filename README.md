## ✨ Features

- 🎙️ إدارة أكثر من 50 بوت صوتي.
- 🏠 تحديد قناة صوتية رئيسية.
- 🔀 نقل البوتات وفصلها وإعادتها.
- 🎛️ لوحة تحكم تفاعلية بالأزرار.
- 🌐 دعم العربية والإنجليزية.
- 👑 إدارة المالك والإداريين.
- 💾 حفظ الإعدادات بعد إعادة التشغيل.
- 🔄 إعادة اتصال تلقائية.
- ➕ إضافة وحذف البوتات من اللوحة.

## ⚙️ Requirements

- Node.js `22.13+`
- Discord Bot Token
- Owner ID
