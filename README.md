## ✨ Features

- 🎙️ إدارة أكثر من 50 بوتًا صوتيًا.
- 🏠 تحديد قناة صوتية رئيسية.
- 🔀 نقل البوتات أو فصلها وإعادتها.
- 🎛️ لوحة تحكم تفاعلية بالأزرار.
- 🌐 دعم اللغتين: العربية والإنجليزية.
- 👑 إدارة المالك والإداريين.
- 💾 حفظ الإعدادات بعد إعادة التشغيل.
- 🔄 إعادة اتصال تلقائية.
- ➕ إضافة وحذف البوتات من اللوحة.

---

## ⚙️ Requirements

- Node.js 22.13+
- Discord Bot Token
- Owner ID

---

## 🚀 Installation

```bash
npm install
npm start
```

---

## 🔑 Environment Variables

```env
DISCORD_TOKEN=YOUR_BOT_TOKEN
OWNER_ID=YOUR_DISCORD_ID
DEFAULT_LANG=ar
```

## 🔐 Security

> ### ⚠️ تنبيه أمني
>
> - لا تشارك توكنات البوتات.
> - لا ترفع ملفات `.env` أو `tokens.txt` إلى GitHub.
> - استخدم بوتات Discord الرسمية فقط.
> - لا تضع التوكنات داخل ملفات عامة أو منشورات.
