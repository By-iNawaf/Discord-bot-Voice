> **Powered Vault**
>
> Developed by [By-inawaf](https://github.com/By-inawaf) — Copyright © 2026 Vault (By-inawaf)

لوحة تحكم **ثابتة** (Discord Components V2) تدير عشرات البوتات الصوتية (50 فأكثر): تتجمع كلها في قناة رئيسية يحددها العميل وتبقى ثابتة 24/7. كل التحكم **بالأزرار فقط**، بلغتين (عربي / English) وبتصميم موحّد.

## ✨ المميزات
- 🏠 **قناة رئيسية** يحددها العميل: تتجمع فيها كل البوتات وتبقى ثابتة، ويعدّلها وقتما يشاء.
- 🔀 **نقل البوتات**: اختر بوتًا أو أكثر (أو الكل) ثم القناة الصوتية.
- 🔌 **فصل البوتات**: فصل المحدد أو فصل الجميع (بتأكيد)، ويبقى البوت مفصولًا حتى يُنقل أو يُرجع.
- ↩️ **إرجاع للرئيسية**: للمحدد أو للكل.
- ➕ **إضافة بوت من اللوحة**: تلصق التوكن فيُتحقق منه ويُكتب في `tokens.txt` تلقائيًا ويبدأ العمل فورًا (للمالك فقط).
- 🗑️ **حذف بوت** من اللوحة (للمالك فقط) مع إزالة توكنه.
- 🌐 **زر اللغة**: عربي ⇄ English، ويغيّر كل شيء بنفس التصميم.
- 👥 **إداريون من الزر**: الصلاحية من قائمة محفوظة وليس برتبة Administrator.
- 💾 **كل شيء محفوظ**: بعد إيقاف البرنامج وتشغيله يرجع كل بوت لحالته الأخيرة (قناة رئيسية / نقل فردي / مفصول)، مع اللغة والإداريين والإعدادات.
- 🎨 **إيموجيات تعمل في كل السيرفرات**: تُرفع تلقائيًا كإيموجيات للتطبيق.
- 👁️ **معاينة مباشرة** للوحة وأزرارها قبل التشغيل (من المحادثة التي وصلتك مع هذه الحزمة).
- 🙈 كل ردود الأزرار **مخفية** لصاحب الضغطة، واللوحة **لا تتكرر** أبدًا، وسجل صامت بدون إشعارات.
- 🔐 لا تحتاج **أي Intent حساسة**، ولا مكتبات native (قاعدة البيانات مدمجة في Node).

## 📋 المتطلبات
- **Node.js 22.13 أو أحدث**
- ذاكرة: تقدير تقريبي **30–60MB لكل بوت متصل** (50 بوت ≈ 1.5–3GB). يُنصح بخادم 4GB لـ 50 بوت.
- قرص دائم لمجلد `data/` (قاعدة البيانات) وملف `tokens.txt`.

## 🚀 التثبيت على 
1. أنشئ سيرفرًا بـ **Node.js egg** واختر صورة **Node 22** أو أحدث.
2. ارفع محتويات المجلد (`index.js` و`emojis.js` و`tokens.txt` و`package.json` ...) إلى المجلد الرئيسي.
3. في **Startup** اجعل ملف التشغيل `index.js` (والحزم تُثبَّت تلقائيًا من `package.json`؛ أو نفّذ `npm install` من الكونسول).
4. في **Startup / Variables** أضف (أو أنشئ ملف `.env` بنفس الأسماء):
```env
DISCORD_TOKEN=توكن_بوت_اللوحة
OWNER_ID=معرّفك            # يمكن أكثر من معرّف مفصولين بفاصلة
```
5. شغّل السيرفر.

**استضافات أخرى / VPS:** `npm install` ثم `npm start`. للتشغيل الدائم: `npm i -g pm2 && pm2 start index.js --name vault-voice && pm2 save`.

### المتغيرات
| المتغير | الوصف | الافتراضي |
|---|---|---|
| `DISCORD_TOKEN` | توكن بوت اللوحة (**مطلوب**) | — |
| `OWNER_ID` | معرّف المالك (**مطلوب**) | — |
| `PANEL_CHANNEL_ID` | روم اللوحة (أو استخدم `/setup`) | — |
| `LOG_CHANNEL_ID` | روم اللوق (أو من اللوحة) | — |
| `WEBSITE_URL` | رابط زر «موقعنا» | `https://vault.bynawaf.xyz` |
| `DEFAULT_LANG` | لغة البداية `ar` / `en` | `ar` |
| `TOKENS_FILE` | مسار ملف التوكنات | `./tokens.txt` |
| `LOGIN_GAP_MS` | فاصل تسجيل دخول كل بوت (مللي ثانية) | `2500` |
| `JOIN_CONCURRENCY` | عمليات الدخول للصوت المتزامنة | `3` |
| `DB_PATH` | مكان قاعدة البيانات | `./data/voice.sqlite` |

## 🤖 إعداد البوتات في Discord
**بوت اللوحة (بوت واحد):** من Developer Portal انسخ التوكن (لا تفعّل أي Intents). ادعُه بصلاحيات `View Channels` + `Send Messages` ونطاقات `bot` + `applications.commands`.

**البوتات الصوتية (بوت لكل توكن):** لا تحتاج أي Intents. ادعُ كل بوت إلى السيرفر بصلاحيتي **View Channel + Connect** (رابط الدعوة: `https://discord.com/oauth2/authorize?client_id=<معرّف_البوت>&scope=bot&permissions=1049600`).
> التوكنات يجب أن تكون لبوتات رسمية فقط. توكنات حسابات المستخدمين غير مدعومة وممنوعة في Discord.

### أول استخدام
1. اكتب `/setup channel:#الروم` (للمالك) ← تُرسل اللوحة.
2. **إضافة بوت** ← الصق التوكن (أو ضع التوكنات في `tokens.txt`).
3. **القناة الرئيسية** ← اختر القناة الصوتية ← تتجمع كل البوتات فيها.
4. **الإداريون** ← أضف من تريد. **السجل** ← حدد روم اللوق.

### ⚠️ شروط القناة الصوتية
- **حد المستخدمين = 0 (بلا حد)** أو أكبر من عدد البوتات، وإلا لن يدخل الزائد.
- كل بوت يحتاج **View Channel + Connect** في القناة.

## 🎛️ دليل الأزرار
| الزر | ما يفعله |
|---|---|
| **القناة الرئيسية** | تحديد/تغيير القناة التي تتجمع فيها كل البوتات (التغيير بتأكيد وينقل الكل) |
| **نقل البوتات** | اختر بوتات (بصفحات 25 أو «تحديد الكل») ثم القناة الصوتية؛ و«إرجاع المحدد للرئيسية» |
| **فصل البوتات** | «فصل المحدد» أو «فصل الجميع» (بتأكيد) |
| **حالة البوتات** | كل بوت وقناته الحالية أو سبب تعذّر اتصاله |
| **إعادة الاتصال** | يصلح غير المتصل فقط، ولا يمس السليم ولا المفصول عمدًا |
| **إرجاع الكل للرئيسية** | يرجع كل البوتات للقناة الرئيسية (بتأكيد) |
| **إضافة بوت** | لصق توكن ← تحقق ← كتابة في `tokens.txt` (للمالك) |
| **الإداريون / السجل** | إدارة من يستخدم اللوحة / آخر الأحداث وتحديد روم اللوق |
| **الإعدادات** | نقل اللوحة، إعادة إنشائها، حذف بوت (للمالك) |
| **English / العربية** | تبديل لغة اللوحة بالكامل |
| **موقعنا** | رابط موقعك |

للمالك فقط: إضافة بوت، حذف بوت، إدارة الإداريين، نقل اللوحة وإعادة إنشائها.

## 💾 الثبات
- القناة الرئيسية، النقل الفردي، حالة الفصل، اللغة، الإداريون، وروم اللوحة ورسالتها: **كلها في قاعدة البيانات**.
- بعد إعادة التشغيل: كل بوت يسجل دخوله بفاصل بينها ثم يعود لحالته (البوت الذي لم تُعدّل إعداداته يتبع القناة الرئيسية، والمفصول يبقى مفصولًا).
- فحص دوري كل 30 ثانية يعيد أي بوت خرج أو سُحب يدويًا (اللوحة هي المتحكم الوحيد).
- لا تُرسل لوحة جديدة مع كل تشغيل، وإن حُذفت الرسالة تُعاد تلقائيًا.

## 🎨 ملف الإيموجيات (`emojis.js`)
لكل إيموجي **اسم + صورة** (رابط أو مسار أو base64). يرفعها البوت تلقائيًا عند التشغيل كـ **إيموجيات للتطبيق (Application Emojis)** فتظهر في **أي سيرفر** حتى لو لم يملكها. لتغيير صورة: ضع صورة جديدة **باسم جديد** وأعد التشغيل. `fallback` رمز بديل إذا فشل الرفع، و`ENABLED = false` يوقف الإيموجيات. الحد 2000 إيموجي للتطبيق، وحجم الصورة حتى 256KB.

| الأزرار «انتهت صلاحيتها» | افتح الصفحة من اللوحة الرئيسية مجددًا |
| `البوت لن يعمل بعد حذف الحقوق` | تم تعديل حقوق المطوّر؛ أعد تحميل النسخة الأصلية |

## English summary
A persistent Components V2 panel that keeps dozens of voice bots (50+) parked in voice channels — buttons only: set the main channel, move / disconnect / return bots (selected or all), add a bot token from the panel (written to `tokens.txt` automatically), manage administrators, and switch the whole panel between Arabic and English. All state survives restarts. Requires **Node.js ≥ 22.13**; no native modules. Pterodactyl: upload the files, set the startup file to `index.js`, and set `DISCORD_TOKEN` and `OWNER_ID`. To re-encrypt after editing: `npm install && npm run protect`, then upload the contents of `release/`.
